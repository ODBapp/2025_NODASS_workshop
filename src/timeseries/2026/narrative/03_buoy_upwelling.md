# C. 在地應用：龍洞浮標 + STL + 湧升指數

> 對應程式：`03_buoy_upwelling.py`
> 時間預估：約 20 分鐘
> 資料：國海院 (NAMR) 提供的龍洞波浪浮標（時頻，2010–2024）

## 這一段在教什麼

前兩段用的是全球/遠方的資料。這一段把學到的工具用在**台灣在地、國海院自己的資料**上，
並示範一個很重要的資料技能：**把原始觀測變成有物理意義的指標**。

三個重點：

1. 浮標 SST 的**季節循環很強**（對比 B 段赤道的弱季節）。
2. 重用 **STL** 取季節 / 趨勢 / 殘差。
3. 由風速、風向算出物理量「**湧升指數 (Upwelling Index, UI)**」，再誠實地檢驗它與 SST 的關係。

---

## C1　浮標資料概覽：強季節

龍洞浮標是**時頻 (hourly)** 資料，但缺值不少（約 7 成）。先 resample 成月平均看大圖。

- SST 全年擺動約 **10°C**（冬約 18°C、夏約 29°C）——**這裡季節才是主角**。
- 對照 B 段：赤道 Niño 3.4 的季節只有 1.3°C。**同樣是「海溫」，季節強弱差很多**，
  這會影響你分析時要不要先把季節拿掉、以及怎麼拿掉。
- 圖上看得到資料缺口（如 2016、2021）——真實資料就是會有洞，這也是要面對的。

---

## C2　重用 STL：強季節 + 殘差

把日平均 SST 丟給 `STL(period=365)`。處理步驟（程式裡）：

1. `interpolate(limit=6)`：只補 ≤ 6 小時的小缺口（大缺口不硬補）。
2. 48 小時滑動平均：抑制高頻雜訊。
3. resample 成日平均。

和 B 段不同，這裡 STL 的 **seasonal 振幅很大**。

> ⚠️ **看 trend 面板：它不是單調暖化，而是上下起伏（會抖）。**
> 因為這裡**沒有鎖 `trend=`**（對比 A5 鎖了 181），STL 的趨勢較「軟」，把年代際的緩慢振盪
> 也算進了趨勢——這**不代表**龍洞海溫真有那麼大的年代際變化，而是 STL 固定週期分解的侷限
> （正是附錄 EEMD 想處理的問題）。residual 裡的一些大塊則多半是**資料缺口**造成的插值假影。
>
> **正因如此，待會湧升比較時 SST 端不用這條 STL 殘差、改用「距平」**（理由見 C4）。
> 這裡先示範 STL 在強季節資料上一樣拆得動。

---

## C3　由原始風資料算「湧升指數 (UI)」

這是本段的精華技能：**把原始觀測 → 物理量**。

> 風速 + 風向 → 風應力沿岸分量 → 除以（海水密度 × 科氏參數）→ 離岸 Ekman 輸送 = UI

- **UI 為正 = 有利湧升**（離岸輸送把底層冷水帶上來）。公式見 Huang et al. 2021。
- 程式把物理寫在 `ts_utils.upwelling_index()`，這裡只要呼叫它。
- **UI 的季節氣候平均**（右圖）：夏季（6–8 月）為正、冬季為負——
  代表夏天的風場比較有利湧升。這個季節型態是穩健、可解釋的（物理上合理）。

---

## C4　沿用一篇 SCI 論文的方法，用浮標資料驗證（Huang et al. 2021）

這一段**沿用** Huang et al. 2021（*Remote Sensing*, <https://www.mdpi.com/2072-4292/13/2/170>）
的湧升指數方法，但改用**國海院的浮標資料**來示範。

**先說清楚論文原本做什麼**（這樣學員才知道我們是「改編／驗證」而非逐行重做）：

- 論文用 **CFSv2 再分析風場 + Himawari-8 衛星 SST**（不是浮標）。
- UI 公式（本程式的 `ts_utils.upwelling_index` 完全照論文 eq 1–4）：
  `UI = ρa·Cd·V²·cos(α−β) / (f·ρw)`，`Cd=(0.8+0.065V)×0.001`，岸線角 **β=18°（北段，龍洞所在）**。
- 論文定義「顯著湧升風事件」（連續 ≥5 天正 UI、前 5 天累積 ≥2.0），再比對衛星偵測到的湧升，
  主結果是 **「湧升風天數 ↔ 衛星湧升天數」r = 0.96 (n = 50)**，並指出
  **「湧升訊號會比風事件落後幾天」**（冷水從深層上湧需要時間）。

**我們的教學改編**：用同一條 UI 公式，但拿龍洞浮標的風算 UI、浮標的 SST 看降溫，
驗證論文那句「湧升落後風場」——

**機制 / 假設**：一陣**有利湧升的風** → 把底層冷水帶上來 → SST 過 1～2 天**下降**
（預期**負相關、UI 領先 SST**）。

前置：**UI** 取 STL **殘差**、**SST** 取**距平**（都回扣主軸「只比較異常」），聚焦 2016 上升流季（4–10 月）。

> ❓ **為什麼 UI 用 STL，SST 卻只用距平、不再 STL？**
> 因為**距平本身已經減過一次月氣候平均**，等於已經把 SST 的季節與大部分長期趨勢去掉了；
> 若再對它做 STL，等於**重複去趨勢、會把訊號裡有用的資訊也削掉**（over-removing）。
> UI 沒有先做距平，所以才用 STL 去季節去趨勢。
> （完整的「換不同處理會怎樣」對照，見附錄 `appendix_ui_xcorr`。）

> 💡 距平基準：原始教材用「上一單元海洋熱浪算出的 OISST 月氣候平均」當基準（把兩單元串起來）；
> 這個 2026 版改用浮標自身的月平均，較自洽，結果幾乎一樣（r 約 −0.33 vs −0.38）。

### C4a　先用眼睛確認 pattern（時間序列疊合）

相關統計圖**不直覺**，所以先把 **UI 與 SST 距平疊合**在同一張時間序列圖上，用眼睛看：
**UI 衝高時，SST 距平是不是隨後往下掉？**

- 這一步的用意：因為我們換了資料源（浮標，而非論文的衛星），**一開始並不確定論文 Fig. 3 的
  pattern 還在不在**。先疊合確認「確實看得到反相位」，才值得做後面的量化。
- 圖上幾個明顯的 UI 尖峰（如 2016-07、2016-09 底）之後，SST 距平都隨即下掉——pattern 存在。
- 教學上把直覺的時間序列圖放前面，學員比較容易進入狀況；統計圖當最後的結論。

### C4b　再量化（落後互相關，最後的結果）

眼睛看到的，用數字確認：

| 最佳落後 | 相關 r | 解讀 |
|---|---|---|
| **+1 天** | **−0.33** | 有利湧升的風**領先** SST 下降約 1 天 ✓ 與論文「湧升落後風場」一致 |

> ✅ 圖上看得很清楚：在**正落後側**（UI 領先）相關是**負的**，lag = +1 天最強。
> 這正是湧升的降溫效應：風先來，海溫隨後一天下降。

> 🔎 小提醒（仍呼應整堂主軸）：這是**聚焦上升流季的單站**結果。
> 論文進一步用**衛星空間資料**看整片海域；單站浮標是很好的**地面驗證 (ground truth)**。
> 換季節、換站，訊號會弱很多——所以解讀時仍要說清楚「在什麼條件下成立」。

**怎麼讀互相關圖（給第一次看的人）：**

- **x 軸 = 落後天數**。`lag = +k` 表示「把 SST 往後挪 k 天去對齊 UI」，問的是
  「今天的 UI 和 k 天後的 SST 有沒有關係」（正 lag = UI 領先）。
- **y 軸 = 相關 r**（−1～+1）。**負的**代表「UI 高 → SST 低」，正是湧升的**降溫**。
- 所以專看**右半邊（正 lag）有沒有明顯負值**：這裡 lag=+1、r≈−0.33 最強。
- ⚠️ r≈−0.33 屬**中等偏弱**；相鄰 lag 的相關**彼此不獨立**，別只盯單一 p<0.05，
  要看整體形狀（右半邊一路是負的）。

### C4c　回扣 B 段：換個時間窗，結論會不會變？

B 段教過「定義 / 選擇會影響結論」。在 C 段我們也親手驗一次——換幾個時間窗算同一件事：

| 時間窗 | best lag | r |
|---|---|---|
| 2016 上升流季 | +1 天 | −0.33（湧升降溫 ✓） |
| 2018 上升流季 | −12 天 | +0.23（符號都反了！） |
| 全紀錄 2010–2024 | 0 天 | −0.10（很弱） |

> 🚨 **換個窗，best lag 和 r 就變了**——這正是 B 段的精神在 C 段再現一次。
> 所以我們才**刻意聚焦在「有物理意義的上升流季」**，並誠實說明這是單站、弱訊號的驗證，
> 不是「放諸四海皆準」的定律。**選擇會影響結論——這是做專題最該內化的一課。**

## 重點回顧

- 同樣是 SST，**季節強弱因海域而異**（龍洞強、赤道弱）。
- **STL** 在強季節資料上一樣好用；要比較的訊號在**殘差 / 距平**。
- **把原始觀測變成物理量 (UI)** 是很有價值的資料技能。
- **沿用一篇 SCI 論文的方法**（UI 公式、β=18°），用國海院浮標資料驗證：
  湧升領先 SST 降溫約 1 天（r ≈ −0.33），與論文「湧升落後風場」一致。
- 但要誠實區分：論文原始是用衛星空間資料、主結果 r=0.96；我們是單站的改編驗證。
- 解讀時仍要講清楚**成立的條件**（季節、單站 vs 空間）——這是做專題的嚴謹。
